# Mercury Global Systems

Frontend-only static site for Mercury Global Systems.

## Structure

- `index.html`, `services.html`, `ventures.html`, `shop.html`, `contact.html`, `industries.html`: frontend pages
- `assets/images/mgs-logo.svg`: official MGS logo asset
- `assets/images/mgs-favicon.svg`: place the official favicon asset here
- `assets/icons/`, `assets/documents/`: frontend asset directories
- `css/style.css`: shared styles
- `js/main.js`: shared frontend interactions
- `config/`, `api/`, `database/`: reserved for the future backend phase

No PHP, MySQL, or backend functionality is included in this frontend pass.
